# EDITH mechanical CAD

This directory contains the **V2.4 concept model** of E.D.I.T.H. eyewear.

| File | Purpose |
| --- | --- |
| [edith-v2.4.kcad.ts](edith-v2.4.kcad.ts) | Editable source captured from [kernelCAD revision 16](https://app.kernelcad.com/p/Ru_P5aCU?version=16) |
| [edith-glasses-v2.4.step](edith-glasses-v2.4.step) | Existing STEP geometry for inspection and reference |

## Model scope

The source contains a styled assembled eyewear concept and a separate, exploded **nine-piece** print-fit study. Its electronics, cameras, AR optics, fasteners, and optical prescription features are **provisional envelopes or cosmetic representations**, not validated parts.

The source can be inspected in kernelCAD. The STEP file was uploaded separately; it has **not been independently verified** as a byte-for-byte export of revision 16.

## Before manufacturing

1. Measure real head, bridge, and ear geometry and test physical fit.
2. Select real hinge hardware, model clearances and folding motion.
3. Validate covers, screw bosses, wall thickness, and printable tolerances.
4. Design around actual display optics, electronics, battery protection, and thermal limits.
5. Do not rely on the modeled lenses for prescription correction.

The model is **research CAD, not production-ready eyewear**.
